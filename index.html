CVU Tools

One bookmark for all the NIDMS and N-VIS tools. It always loads the latest version.

CVU Tools
  1. Show your bookmarks bar (Ctrl+Shift+B).
  2. Drag the CVU Tools button above onto the bar.
  3. Open NIDMS or N-VIS and click it. A menu shows the tools for that site.

Delete the old CVU Tools folder — this one bookmark replaces it, and updates itself.

Batch search, matches passport and R number.
NIDMSRefusal reasons
Grounds, sent to L1 (date, by), refused (date, by), internal comments.
NIDMSPassport duplicate check
Duplicates in a list and status of every application.
